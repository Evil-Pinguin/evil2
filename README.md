# D01T01 — тренажёр «Знакомство с Linux и Git-системой»

Минималистичное веб-приложение для подготовки к проекту **D01T01** (School 21):
весь материал квестов 1–10, вопросы по командам и разбор кода. Без фреймворков и сборки —
чистые HTML/CSS/JS, работает офлайн.

## Что внутри

**Главный экран** — четыре режима, фильтр по дням, статистика и кнопки темы/сохранения.

| № | Режим | Что делает |
|---|-------|-----------|
| 01 | **Читать** | Материал карточками: цель квеста, шаги, команды с копированием, ожидаемый вывод, diff, итог. Квесты 1–7 + бонус 8–10, финальная проверка, маршрут сдачи и шпаргалка по командам. |
| 02 | **Команды** | Дана задача — выбрать правильную команду или часть кода (4 варианта). |
| 03 | **Разбор кода** | Дана команда — выбрать, что она делает. |
| 04 | **Повторение** | Сложные и отмеченные вопросы: смешанные задания по всем дням. Наполняется автоматически. |

**Фильтр по дням** (сверху, применяется ко всем режимам):

* `Все дни` — Quest 1–10;
* `День 1` — Quest 1–4 (клонирование, AI-модуль, двери);
* `День 2` — Quest 5–7 + финальная проверка (первая дверь, ключи, ветки);
* `Бонус` — Quest 8–10 (Vim, скрипт, GitLab-мануал).

### Перелистывание вопросов

Под карточкой вопроса — полоса плашек `1 … N`: клик переходит к любому вопросу, плашка показывает
состояние (верно / ошибка / без ответа / отмечен ★). Кнопки `Назад` и `Дальше` листают сессию,
возврат к уже отвеченному вопросу показывает прежний ответ и пояснение. В режиме чтения такая же
полоса работает как оглавление.

### Подсказки

Кнопка `✦ Подсказка` в карточке вопроса:

1. первое нажатие — текст подсказки к вопросу (у каждого из 56 вопросов своя формулировка);
2. второе — `Убрать два неверных`: остаются два варианта, лишние зачёркиваются.

Использованные подсказки учитываются в статистике и отмечаются в разборе ошибок.

### Отметка «Повторить» и повторение

* Кнопка `☆ Повторить` в карточке вопроса (или клавиша `m`) помечает вопрос — он попадёт в повтор и в режим `04 Повторение`.
* Вопрос, где была ошибка, автоматически попадает в список «сложные».
* В конце основной части сессии открывается этап **Повторение**: все отмеченные и ошибочные вопросы
  задаются заново, варианты перемешаны, ответы сброшены. Кнопка `К итогам` позволяет пропустить этап.
* На итогах — разбор ошибок, списки «Отмечено для повтора» и «Сложные вопросы», кнопки
  `Повторить сессию`, `Повторить сложное · N` и `Скачать файл прогресса`.
* Верный ответ в повторении уменьшает счётчик ошибок вопроса; когда он доходит до нуля, вопрос уходит из «сложных».

### Две темы

Тёмная (по умолчанию) и светлая. Переключатель — кнопка темы в шапке, на главном экране или клавиша
`t`. Первый запуск следует системной настройке `prefers-color-scheme`; выбранная тема запоминается
и применяется до первой отрисовки, поэтому страница не «мигает».

### Локальное сохранение

Всё хранится в `localStorage` браузера (ключ `d01t01.progress.v2`), ничего не отправляется в сеть:

* выбранная тема и день, прогресс чтения, лучшие результаты, статистика ответов и подсказок;
* отметки «повторить» и список сложных вопросов;
* незавершённая сессия (черновик): на главном экране появляется баннер `Продолжить: Команды — вопрос 7 из 24`.

Панель **Сохранение** (кнопка `⤓` в шапке, на главном экране или на итогах) показывает время последнего
сохранения, размер данных, счётчики и позволяет:

* `Скачать файл прогресса` — экспорт в JSON (`d01t01-progress-ГГГГ-ММ-ДД.json`);
* `Загрузить из файла` — импорт из JSON (заменяет текущие данные);
* `Скопировать JSON` — прогресс в буфер обмена;
* `Сбросить прогресс` — удаление локальных данных (в два нажатия).

Данные версии 1 автоматически переносятся в новую схему при первом запуске.

## Клавиатура

| Клавиши | Действие |
|---------|----------|
| `←` / `→` (или `Enter`, пробел) | листать карточки и вопросы |
| `1`–`4` | ответ, на главном экране — выбор режима |
| `h` | подсказка (повторное нажатие — убрать два неверных) |
| `m` | отметить вопрос кнопкой «Повторить» |
| `t` | переключить светлую/тёмную тему |
| `c` | продолжить сохранённую сессию |
| `esc` | закрыть панель или выйти на главный экран |

На мобильных работают свайпы влево/вправо (чтение и вопросы).

## Отклики и анимации

Подсветка верного/неверного варианта, частицы при правильном ответе, «дрожание» при ошибке,
выезжающая панель с пояснением и правильным ответом, прогресс-бар, анимированный круг результата,
плавные переходы между карточками, `prefers-reduced-motion` уважается.

## Запуск

```bash
# вариант 1: встроенный статический сервер (без зависимостей)
node serve.js 5173        # http://localhost:5173

# вариант 2: любой другой сервер
python3 -m http.server 5173

# вариант 3: просто открыть index.html в браузере
```


### Как пополнять контент

Всё содержимое — в `assets/js/data.js`, код трогать не нужно:

* `quests[]` — карточки квестов (`title`, `goal`, `steps[]` со `cmds`, `out`, `diff`, `note`);
* `items[]` — банк команд; из него автоматически собираются оба квиза:
  * `cmd` — сама команда или фрагмент кода,
  * `task` — формулировка задачи для режима «Команды»,
  * `what` — описание того, что команда делает (режим «Разбор кода»),
  * `why` — пояснение в отклике после ответа,
  * `hint` — текст подсказки (если её нет, подсказка будет выведена из ответа),
  * `day` — `d1` / `d2` / `bonus` (попадание в фильтр),
  * `fam` / `dom` — семейство команды и область применения: дистракторы
    подбираются из других семейств, чтобы варианты не дублировались и не были очевидными,
  * `modes` — необязательное ограничение (`['what']` — только в разборе кода);
* `cheatsheet`, `flow`, `final`, `intro` — блоки чтения.

Число вопросов в каждом режиме пересчитывается автоматически из `items` и текущего фильтра дня.
В режим «Повторение» вопрос попадает из отметок пользователя или после ошибки.
